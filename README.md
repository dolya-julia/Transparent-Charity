# Transparent-Charity

## Карточки героя (RescueHeroCards)

Добавлен контракт `contracts/RescueHeroCards.sol`. Он выпускает отдельную NFT-карточку
для каждой пары «донор — заявка», если у заявки уже выпущен NFT-паспорт `RescueNFT`.
Повторные пожертвования на ту же заявку не создают дубликат: они увеличивают общий вклад
карточки и добавляют запись в её историю участия. У каждой карточки есть уникальный
порядковый номер, ID заявки и ID связанного NFT-паспорта.

### Развертывание и подключение

1. Скомпилируйте и разверните `RescueHeroCards.sol`, передав в конструктор два аргумента:
   адрес `RescueDAO` и адрес `RescueNFT`.
2. Вызовите от администратора DAO функцию `setHeroCardsContract(address)` и передайте
   адрес развернутого `RescueHeroCards`.
3. В `frontend/js/config.js` укажите этот же адрес в `HERO_CARDS_ADDRESS`.
4. Откройте страницу `frontend/badges.html` («Мои достижения»). В профиле появится
   коллекция карточек героя и история участия по каждой карточке.

Карточки создаются за целевые пожертвования (`donateToRequest`). Пожертвование в общий
фонд не связано с конкретным животным и поэтому не выпускает карточку. Карточка
выпускается автоматически при первом целевом пожертвовании, а последующие операции
накапливаются в истории. Контракт использует ERC-721 Enumerable для получения коллекции
владельца.

**Важно:** после добавления нового адреса в DAO и конфигурацию фронтенда необходимо
перезапустить локальное приложение. Уже совершённые до подключения `RescueHeroCards`
пожертвования автоматически карточки не создают.
